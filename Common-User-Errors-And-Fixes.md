# Common Errors And Thier Fixes
Common typical and common user errors and thier fixes.

## `ERR_INSUFFICIENT_FUNDS` 
* **Problem:** This happens when you try to stake without enough Sepolia ETH for gas fees.
* **Fix:** Use a Sepolia faucet to get more test ETH, then retry transaction again.

## `Error 4001` 
* **Problem:** This means user rejected the transaction in MetaMask or any other wallet in use.
* **Fix:**  Affected user should try again and click `accept` in thier wallet instead of `Reject`.

## ​`ERR_CONTRACT_PAUSED`
* **Problem:** If you see this it's not your fault, we pause the protocol for maintenance.
* **Fix:**   Wait for an hour and retry.
